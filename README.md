## 4. 飲食指南

**不吃：** 牛、豬、內臟、鰻魚、生食
**口味參考：** 雞肉料理、熟的海鮮、烤魚、燉魚、韓式料理、雪冰等（舉例，不是必吃清單）

### 在日本可以放心點的

| 類型 | 點法 |
|---|---|
| 天ぷら、天丼 | 炸蝦、炸魚、炸蔬菜都可以 |
| 焼き魚定食（烤魚定食） | 鯖魚、鮭魚、花魚（ホッケ） |
| 唐揚げ（日式炸雞） | 直接點 |
| 焼き鳥（烤雞串） | 只點もも（雞腿）、ねぎま（雞肉蔥段）、手羽先（雞翅）。**不點**レバー（肝）、ハツ（心）、砂肝（雞胗）這些內臟，也不點豚バラ（豬五花）；つくね（雞肉丸）有時混豬肉，要先問 |
| もんじゃ、お好み焼き | 選海鮮或明太子口味，不點豬肉、牛筋口味 |
| そば、うどん | 天ぷらそば、きつねうどん（豆皮）；不點肉そば、肉うどん、カレーうどん |
| 深川めし、玉子焼き | 可以 |

### 容易踩雷的地方

| 類別 | 風險 | 處理方式 |
|---|---|---|
| 拉麵 | 湯頭多是豬骨或混合高湯，叉燒是豬肉 | 不點 |
| 日式咖哩 | 雞肉咖哩的醬底也常用牛、豬油脂 | 不點 |
| 煎餃、關東煮 | 煎餃內餡是豬肉；關東煮常有牛筋，湯可能被燉過 | 不點 |
| 蛋 | 親子丼、壽喜燒、溫泉蛋常用半熟或生蛋 | 不點，或請店家煮全熟 |
| 生食 | 壽司、生魚片、海鮮丼、生蠔、生吻仔魚（生しらす） | 不點 |
| 鰻魚 | うな重、ひつまぶし | 不點 |
| 便利商店 | 成分標示 | 看「原材料名」，避開：豚肉、牛肉、ポーク、ビーフ、ゼラチン（明膠多為豬來源，依自己的標準判斷） |
| 韓式餐廳（如果有去） | 刀削麵可能用牛骨湯；辣炒年糕常加牛肉粉「ダシダ」；紫菜飯捲有火腿；小菜泡菜可能有生蝦醬、生蠔 | 先問湯底與調味；飯捲請店家拿掉火腿 |

### 點餐用語（給店員看）

| 情境 | 日文 |
|---|---|
| 說明飲食限制 | 牛肉・豚肉・内臓・うなぎ・生もの（刺身、生卵）が食べられません。 |
| 問有沒有豬肉、牛肉 | これに豚肉や牛肉は入っていますか？ |
| 問湯底 | このスープは何でだしを取っていますか？ |
| 蛋要全熟 | 卵はしっかり火を通してください。 |
| 去掉火腿 | ハムを抜いてください。 |

### 迪士尼園內用餐

- 官方「食物過敏資訊」可以**依原料搜尋**，原料清單包含牛肉、豚肉，用來挑不含牛豬的餐點：[fsp.tokyodisneyresort.jp](https://fsp.tokyodisneyresort.jp/)
- 官方「低過敏原」蔬菜咖哩飯（ベジタブルカレーライス）不含牛、豬、雞：[官方頁面](https://www.tokyodisneyresort.jp/food/981/)
- 官方規定：有飲食限制的人可以把自備食物帶進餐廳吃：[お食事に制限のある方へのご案内](https://www.tokyodisneyresort.jp/tdr/bfree/food.html)
- 實際作法：早上便利商店買的飯糰當備案，園內再查官方資料挑主餐。

### 長榮特別餐

- 長榮官網規定特別餐要在**起飛前 24 小時**預訂（免費），海鮮餐代碼 SFML。
- 回程 BR191：要在 **11/2 12:15（日本時間）前**到長榮官網「選餐」訂。近期有旅客反映海鮮餐選不到，選不到的話打長榮訂位中心。
- 去程 BR192：現在應該已經超過 24 小時期限。

- **10/31 萬聖節夜晚**：澀谷、新宿歌舞伎町人潮擁擠，這天行程都排在飯店附近。
