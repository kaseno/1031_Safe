## 4. 飲食指南

**不吃：** 牛、豬、內臟、鰻魚、生食

### 容易踩雷的地方

| 類別 | 風險 | 處理方式 |
|---|---|---|
| 刀削麵（칼국수） | 湯底可能是牛骨（사골） | 先問湯底，確認是鯷魚（멸치）或蛤蜊 |
| 辣炒年糕、湯類 | 常加「ダシダ（다시다）」，這是牛肉粉調味料 | 點餐前問 |
| 紫菜飯捲 | 火腿、魚肉香腸、烤牛肉口味 | 請店家拿掉火腿；不點「プルコギ（烤牛肉）」口味 |
| 小菜泡菜 | 會加生的醃蝦醬；11 月是醃泡菜季節，新鮮泡菜可能放**生蠔** | 小菜裡的新鮮泡菜不要吃 |
| 韓國料理 | 生醃蟹（ケジャン）、生拌牛肉（ユッケ）、部隊鍋（火腿香腸） | 不點 |
| 日式料理 | 拉麵、咖哩、煎餃、湯底常含豬或牛萃取物；親子丼、壽喜燒常用半熟或生蛋 | 不點拉麵、咖哩；蛋要全熟 |
| 便利商店 | 成分標示 | 看「原材料名」，避開：豚肉、牛肉、ポーク、ビーフ、ゼラチン（明膠多為豬來源，依你的標準判斷） |

### 點餐用語（給店員看）

| 情境 | 日文 | 韓文（新大久保很多店員是韓國人） |
|---|---|---|
| 說明飲食限制 | 牛肉・豚肉・内臓・うなぎ・生もの（刺身、生卵）が食べられません。 | 소고기, 돼지고기, 내장, 장어, 날것은 못 먹어요. |
| 問刀削麵湯底 | このスープは牛骨ですか？煮干しですか？ | 육수가 사골이에요? 멸치예요? |
| 問牛肉粉 | ダシダ（牛肉だし）は入っていますか？ | 소고기 다시다 들어가요? |
| 飯捲去火腿 | キンパのハムを抜いてください。 | 김밥에 햄 빼 주세요. |
| 蛋要全熟 | 卵はしっかり火を通してください。 | 계란은 완전히 익혀 주세요. |

### 迪士尼園內用餐

- 官方「食物過敏資訊」可以**依原料搜尋**，原料清單包含牛肉、豚肉，用來挑不含牛豬的餐點：[fsp.tokyodisneyresort.jp](https://fsp.tokyodisneyresort.jp/)
- 官方「低過敏原」蔬菜咖哩飯（ベジタブルカレーライス）不含牛、豬、雞：[官方頁面](https://www.tokyodisneyresort.jp/food/981/)
- 官方規定：有飲食限制的人可以把自備食物帶進餐廳吃：[お食事に制限のある方へのご案内](https://www.tokyodisneyresort.jp/tdr/bfree/food.html)
- 實際作法：早上便利商店買的飯糰當備案，園內再查官方資料挑主餐。

### 長榮特別餐

- 長榮官網規定特別餐要在**起飛前 24 小時**預訂（免費），海鮮餐代碼 SFML。
- 回程 BR191：要在 **11/2 12:15（日本時間）前**到長榮官網「選餐」訂。近期有旅客反映海鮮餐選不到，選不到的話打長榮訂位中心。
- 去程 BR192：現在應該已經超過 24 小時期限。

### 單人旅行注意事項

- **10/31 萬聖節夜晚**：澀谷、新宿歌舞伎町人潮擁擠，行程刻意避開，晚餐後直接回飯店。
- **迪士尼人潮**：手機與錢包放在前方或有拉鍊的包包，帶行動電源（整天開 App 很耗電）。
